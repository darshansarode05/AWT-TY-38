## Project Description

The Student ID Card Generator is a web application that allows students to enter their personal details and generate a digital student ID card.

The application validates user input, checks the email format, generates a personalized skill level based on the last digit of the roll number, and displays preferred technologies dynamically using JavaScript.

---

## Features

- Student Registration Form
- Input Validation
- Email Validation using Regular Expression
- Dynamic Student ID Card Generation
- Skill Level Generation Based on Roll Number
- Preferred Technologies Display
- DOM Manipulation
- Event Handling
- JavaScript Functions
- Conditional Statements
- Array and forEach() Iteration

1. Download or clone the project.

5. Click **Generate ID Card** to view the generated student information.
